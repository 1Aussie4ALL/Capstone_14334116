# For Capstone Project Showcase Presentation

## PROJECT OVERVIEW
The Original 2Layer Classifier is the foundational MRI brain tumor classification system that solves critical issues in medical image analysis by implementing a two-stage classification approach.

## PROBLEM STATEMENT
Previous models had significant limitations:
- MRI Detection Classifiers: Provided incorrect cancer type predictions
- Brain Tumor Quick Classifiers: Detected cancer in non-MRI images (false positives)
- Single-stage classification: Could not distinguish between MRI and non-MRI images

## SOLUTION ARCHITECTURE

### Two-Layer Classification System
```
Input Image → Layer 1: MRI Detection → Layer 2: Tumor Classification
                ↓                           ↓
            [not_mri] OR [mri]        [glioma/meningioma/notumor/pituitary]
```

### Technical Specifications
- **Base Model**: MobileNetV2 (pre-trained on ImageNet)
- **Input Dimensions**: 128×128×3 RGB images
- **Output Classes**: 5 classes (4 MRI tumor types + 1 non-MRI)
- **Model Size**: ~18.8 MB
- **Training Method**: Transfer learning with fine-tuning

## DATASET COMPOSITION
```
Dataset/Training/ (Total: 5,779 images)
├── glioma/          # ~1,000 MRI images with glioma tumors
├── meningioma/      # ~1,000 MRI images with meningioma tumors  
├── notumor/         # ~1,000 MRI images with no tumors
├── pituitary/       # ~1,000 MRI images with pituitary tumors
└── not_mri/         # ~779 non-MRI images (photos, X-rays, etc.)
```

## TECHNICAL IMPLEMENTATION

### Model Architecture
```python
# Base MobileNetV2 architecture
base_model = MobileNetV2(
    input_shape=(128, 128, 3),
    include_top=False,
    weights='imagenet'
)

# Custom classification head
x = GlobalAveragePooling2D()(base_model.output)
x = Dense(512, activation='relu')(x)
x = Dropout(0.5)(x)
predictions = Dense(5, activation='softmax')(x)
```

### Training Configuration
- **Batch Size**: 32
- **Epochs**: 50
- **Learning Rate**: 0.001
- **Optimizer**: Adam
- **Loss Function**: Categorical Crossentropy
- **Callbacks**: ModelCheckpoint, EarlyStopping, ReduceLROnPlateau

### Data Preprocessing
1. **Image Resizing**: All images resized to 128×128 pixels
2. **Normalization**: Pixel values normalized to [0,1] range
3. **Data Augmentation**: Basic augmentation during training
4. **Class Balancing**: Ensured balanced representation across all classes

## INNOVATION FEATURES

### Two-Stage Classification
- **Layer 1**: Distinguishes medical scans from regular photos
- **Layer 2**: Classifies tumor types only in confirmed MRI images
- **Benefit**: Prevents false cancer detection in non-medical images

### Transfer Learning Implementation
- **Base Model**: MobileNetV2 pre-trained on ImageNet
- **Custom Head**: Specialized layers for medical image classification
- **Advantage**: Leverages general image recognition knowledge

### Robust Architecture
- **Input Flexibility**: Handles various image formats and sizes
- **Output Clarity**: Provides clear, interpretable results
- **Error Handling**: Graceful handling of edge cases

## TECHNICAL CHALLENGES SOLVED

### Challenge 1: False Positive Detection
**Problem**: Previous models detected cancer in non-MRI images
**Solution**: Two-layer system prevents tumor classification unless MRI is confirmed

### Challenge 2: Class Imbalance
**Problem**: Uneven distribution of tumor types
**Solution**: Careful dataset balancing and augmentation strategies

### Challenge 3: Model Generalization
**Problem**: Overfitting to training data
**Solution**: Transfer learning and dropout regularization
