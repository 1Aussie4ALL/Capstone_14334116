==================================================
  UNIFIED MRI CLASSIFIER - SETUP INSTRUCTIONS
==================================================

Welcome! This application runs three deep learning models for brain MRI tumor classification.

QUICK SETUP:
-----------

1. Navigate to the 'setup' folder
2. Run 'setup.bat' to install dependencies
3. Go back to WebAPP folder
4. Run 'run_unified_webapp.bat' or 'python app_unified_classifier.py'
5. Open browser to http://localhost:5000

DETAILED INSTRUCTIONS:
---------------------
See the 'setup' folder for complete documentation:
- setup/README.md       (Full documentation)
- setup/QUICKSTART.md    (5-minute quick start)
- setup/requirements.txt (Python dependencies)
- setup/setup.bat        (Automated setup script)

For Cursor IDE users:
- .cursorrules file contains project context for AI assistance

REQUIREMENTS:
------------
- Python 3.8+
- TensorFlow, OpenCV, Flask, NumPy
- 3 model files (mri_2layer_classifier_final.h5, etc.)
- 8GB+ RAM recommended

Need help? Check 'setup' folder for detailed documentation!
